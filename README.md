# МИНУСРАЗМЕР — статический сайт

Публичный сайт студии в Новосибирске: https://xn--80akfctdeyeev.xn--p1ai/

## Структура

- `index.html` — главная страница.
- `ceny.html`, `programmy.html` — цены и программы.
- `apparatnyy-massazh.html`, `apparatnaya-korrekciya-figury.html` — страницы услуг.
- `pervyy-vizit.html`, `faq.html` — информация для посетителей.
- `privacy.html`, `consent.html`, `offer.html`, `requisites.html` — документы.
- `assets/page-shell.css` — общие стили шапки, подвала и баннера согласия.
- `analytics.js` — загрузка Яндекс Метрики после выбора согласия и цели кликов.
- `schema.json` — структурированные данные организации.
- `sitemap.xml`, `robots.txt` — файлы для поисковых роботов.
- `vercel.json` — HTTP-заголовки и политика безопасности.
- `.github/workflows/site-check.yml` — автоматические проверки.

## Публикация

Репозиторий подключён к Vercel. Изменения следует вносить в отдельной ветке, проверять GitHub Actions и preview deployment, затем объединять pull request в `main`. Не редактируйте production вручную в обход репозитория.

## Важные ограничения

- Не меняйте цены и состав программ без отдельного согласования.
- Не добавляйте выдуманные отзывы, фото клиентов или специалистов.
- Не ослабляйте CSP и не удаляйте разрешения `unsafe-inline`, пока встроенные скрипты и стили не переведены на безопасную схему.
- После переименования изображений обновляйте ссылки в HTML и микроразметке.
